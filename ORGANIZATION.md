# stangyode organization

## Current lifecycle

`ONBOARDED` / `EXECUTION`

The project is an active Melancholy project. Its persistent PM is
`stangyode-pm`, currently working within the approved canonical website scope.
The current milestone is the AI-engineering atlas feature.

## Roles

- Mats: project owner and final approver.
- Melancholy: system-level governance and onboarding.
- stangyode-pm: project-local PM; owns decomposition, bounded delegation,
  evaluation, verification, and PR preparation.
- Builders, QA workers, researchers, and Specialists: disposable bounded
  workers behind the PM.

## Execution boundaries

Implementation remains branch -> push -> pull request -> Mats review/approval ->
merge. Publication, custom-domain changes, deployment automation, credentials,
external integrations, destructive actions, protected branches, and persistent
policy/capability changes remain separately gated.
