# Stangyode

The source for [stangyode.com](https://stangyode.com), the independent technology practice of Mats O. Stangjordet.

Stangyode focuses on secure cloud infrastructure, cybersecurity, automation, and production-minded AI systems.

## Local development

The site is dependency-free and requires a recent Node.js version.

```sh
npm start
```

Open `http://127.0.0.1:4173`.

## Deployment

GitHub Pages serves the `gh-pages` branch with `stangyode.com` as its custom domain. The files in `public/` are the source version of the deployed static site.
